# 在线购书管理系统

> JavaWeb实训项目，图书商城系统

## 项目简介

本项目是基于JavaWeb开发的在线购书管理系统，实现用户注册登录、图书浏览、加入购物车、下单等核心业务功能。
适合Java后端基础练习，代码托管在GitHub。

## 技术栈

后端：Java、Servlet、JSP、JDBC、Maven、Tomcat
数据库：MySQL
前端：HTML、CSS、JavaScript
工具：IntelliJ IDEA、Git

## 功能模块

- 用户模块：用户注册、登录、退出登录
- 图书模块：图书信息展示、图书列表查询
- 购物车模块：添加图书、修改数量、删除购物项
- 订单模块：提交订单、查看订单记录

## 环境要求

- JDK 8
- Tomcat 8.5 / 9
- MySQL 5.7 / 8.0
- Maven 3.6+
